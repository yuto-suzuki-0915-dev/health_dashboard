# DAYFRAME

今日の時間割を決め、予定に沿って行動し、結果を振り返る個人用ダッシュボードです。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示されたローカル URL を開いてください。

## 使い方

1. 「時間割を作成」から起床・作業時刻、Today’s 3、時間ブロックを登録します。
2. 時間ブロックの開始時に `START` を押します。`PAUSE` 中も予定終了時刻は延びません。
3. ブロックを「完了」または「未完了」にします。終了時刻を過ぎた未判定ブロックは画面上部に表示されます。
4. 必要に応じて一覧の「実際の開始」「実際の終了」を修正します。
5. 「明日」タブから翌日の時間割を作成します。日付選択で過去の記録も見られます。

予定遵守率は「完了した時間ブロック数 ÷ 全時間ブロック数」、予定通り開始は予定時刻から5分以内に開始したブロック数です。データはブラウザの `localStorage` に保存されます。ブラウザのデータを消去すると記録も消えます。
