# DAYFRAME

「予定した時間」と「実際に使った時間」を見比べる個人用ダッシュボードです。Next.js と TypeScript で動き、データはブラウザの `localStorage` に保存します。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示されたローカル URL を開いてください。

## ホーム

ホームは3つだけです。

1. **Today's Priority**：今日、一番前に進めることを1つ入力します。
2. **時間割**：各枠の予定と実績を横に並べます。「実績を記録」から実際にしたことと開始・終了時刻を入力すると所要時間が表示されます。「今から開始」「今終了」でも時刻を記録できます。
3. **Weekly Progress**：今期の主要目標を1つ設定し、その週末時点の累計値を記録します。項目名・単位・期間の目標値は自分で決められます。前週との差と目標への到達度を確認できます。未入力の週は前週までの累計を参考表示し、入力を消すとその週の記録だけを取り消せます。期間を変更すると古い週次記録は目標設定画面の履歴に残り、新しい期間は空欄から始まります。

以前の Today’s 3 は、最初の項目を Today's Priority の初期表示に使います。元の記録は削除しません。

## 先の予定を立てる

上部の「予定を立てる」から、週送りまたは日付選択で任意の日を表示します。日付を選んで「この日の予定を編集」を押すと、その日の優先事項と各時間枠の内容を入力できます。週の一覧には予定の先頭項目が表示されます。今日と過去の日付では、時間割から実績を追記・修正できます。

「曜日の固定枠を設定」では、曜日ごとの授業・作業枠と休憩枠を編集できます。初期状態では平日に 1限 8:50–10:20、2限 10:30–12:00、昼休み 12:00–13:30、3限 13:30–15:00、4限 15:10–16:40、5限 16:50–18:20 が入っています。土日は空欄です。既存の標準3限までの当日以降の予定には4・5限を補います。独自に編集した時間割と過去の記録はそのまま残ります。

データは同じブラウザ・同じ URL で保持されます。ブラウザのデータを消去すると記録も消えます。
